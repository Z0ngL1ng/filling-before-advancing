# Benchmark Input Samples

This folder contains small input-only examples from HarborEval-0617, OpenEval, and RSVQA-Harbor. Private reference answers are intentionally omitted.

Published HarborEval/OpenEval example IDs are listed in `PUBLIC_EXAMPLE_EXCLUSIONS.json` and must be excluded from future held-out score reporting. RSVQA examples originate from its public question set.

Images retain their original pixels. The package is SHA-256 deduplicated within and across both showcase folders.
